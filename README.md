### Part 3: Decision Tree Classifier
- Built a decision tree model using Age, BMI, Gender, and Physical Activity.
- Visualized the decision tree.

### Part 4: Model Evaluation

### Naive Bayes Classifier
- Implemented Naive Bayes, assessed its performance using a confusion matrix.

### Logistic Regression
- Developed a logistic regression model, predicted diabetes status, and evaluated accuracy.

## Comparison of Classifiers
- Accuracy metrics indicated slight differences among classifiers, with logistic regression performing marginally better.

## Conclusion
This analysis provides insights into diabetes prediction using various supervised learning techniques, highlighting the strengths and weaknesses of each approach.
